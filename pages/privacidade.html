Política de Privacidade

Esta página é uma versão preliminar para a demonstração do NexaFlow e deverá ser revisada juridicamente antes do lançamento comercial.

Dados tratados

O NexaFlow poderá tratar dados de conta, dados do negócio, informações de clientes e dados necessários para agendamentos.

Finalidade

Os dados serão utilizados para autenticação, gestão da operação, agendamentos, comunicação e melhoria do serviço.

Segurança e isolamento

A versão de produção deverá usar controles de acesso, autenticação e isolamento dos dados de cada empresa. A demonstração atual utiliza armazenamento local do navegador.

Contato

Os canais oficiais de privacidade serão adicionados antes da publicação comercial.
