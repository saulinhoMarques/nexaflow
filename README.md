# NexaFlow

SaaS de gestão para pequenos negócios de serviços.

## Stack atual

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5
- Git / GitHub

## Backend planejado

- Supabase Auth
- PostgreSQL
- Supabase Storage
- Row Level Security (RLS)

## Deploy planejado

- Vercel

## Estrutura


## Visão do produto

O NexaFlow combina presença digital, gestão de clientes, serviços, profissionais e agendamentos em uma única plataforma multi-tenant.
