# NexaFlow

SaaS de gestão para pequenos negócios de serviços.

## Visão

O NexaFlow combina presença digital, gestão de clientes, serviços, profissionais e agendamentos em uma única plataforma multi-tenant.

## Stack planejada

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase / PostgreSQL
- Supabase Auth
- Vercel
- GitHub
